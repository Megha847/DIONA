# PDF Report Recreation – HTML, CSS & JavaScript

## Overview

This repository contains my solutions for the two assigned exercises. The objective was to recreate the provided PDF documents as responsive web pages using **HTML, CSS, and JavaScript**, while supporting dynamic data and maintaining the structure and appearance of the original documents.

## Exercises

### Exercise 1 – Worker Progress Report

The Worker Progress Report recreates the provided PDF with:

* WCB logo and header
* Worker name and claim number
* Return-to-work information
* Checkbox selections
* Recovery information
* Pain/discomfort section
* Medical treatment information
* Additional comments
* Certification and privacy notice
* Footer with Worker App ID, submission date, and page numbers
* Three-page layout

### Exercise 2 – Medical & Travel Expense Request

The Medical & Travel Expense Request recreates the provided PDF with:

* WCB logo and header
* Worker name and claim number
* Prescription drug expenses
* Over-the-counter drug expenses
* Medical supplies
* Parking expenses
* Mileage expenses
* Bus/taxi expenses
* Privacy notice
* Footer with Worker App ID, submission date, and page numbers
* Two-page layout

## Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Layout, styling, tables, borders, spacing, and print formatting
* **JavaScript** – Dynamic data generation and handling

## Dynamic Data

The reports are designed to support different datasets.

For example, the following values can be changed dynamically:

* Worker name
* Claim number
* Dates
* Medical information
* Comments
* Expense details
* Number of expense records
* Amounts
* Healthcare provider details

The table-based sections are designed to support both a small number of records and multiple records.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure the required image/assets are present in the same folder.
4. Open the HTML file in a web browser.

No additional installation or dependencies are required.
